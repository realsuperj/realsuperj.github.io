AGENT SKILL

Skill 收藏整理器

收藏夹里躺着几十上百个 skill，压缩包、PDF、没名字的文件混成一团。
它把这些整理成分好类、编好号、评过分、去过重的一份清单。

你是不是也这样
名字全是 SKILL.md不点开根本不知道是什么，找一个要挨个试
同一个收了三遍v1、v3、还有 PDF 导出版，不敢删也不敢装
混进来一堆不是 skill 的作业、设计稿、别人生成的报告，清单被稀释
不知道哪个值得装有的很完整，有的只有半页大纲，没标准难挑
它怎么做
01清点提取zip / rar / 7z / PDF / docx，没扩展名的也能认
02先分类型不是 skill 的单独放，不占编号不参与排序
03五维评分每条都给具体依据，不是一句「质量不错」
04去重仲裁只有同一 skill 的不同版本才算重复
05编号落盘先给你看完整移动计划，确认了才动手
06出报告附带账本，下次只处理新增的条目
边界写在前面
✓ 它负责
批量解压与文本提取
判断哪些是 skill、哪些只是资料
打分、分类、编号、去重
就地移动改名，动手前先备份
增量整理，编号不重排
✗ 它不负责
把 skill 安装到 AI 客户端
修改任何 skill 的内容
帮你写新的 skill
扫描你指定目录以外的地方
删除文件，重复的只归档
电脑端 · 完整可用能读写本地文件夹就能跑完整流程。有 Python 更快，没有也能走，分批做且支持中断续跑。
手机端 · 只出报告手机智能体动不了本地文件，它会主动降级，第一句就说明「不动文件」，把该怎么整理列成清单。
