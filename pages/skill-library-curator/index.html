Skill 收藏整理器

收藏夹里躺着几十上百个 skill，压缩包、PDF、没名字的文件混成一团。
这个 skill 把它们整理成分好类、编好号、评过分、去过重的一份清单。

它解决什么

如果你也在到处收 skill，这几件事应该很熟悉。

名字全是 SKILL.md，不点开根本不知道是什么 一堆 SKILL.md、SKILL-2.docx、技能设计方案_v5.md，找一个要挨个打开。
同一个 skill 收了三遍，v1、v3、还有 PDF 导出版 不敢删，怕删错。但留着又占地方，安装时也不知道该装哪个。
混进来一堆压根不是 skill 的东西 作业展示、设计稿、别人生成的报告，跟真 skill 混在一起，清单被稀释。
不知道哪个值得装 有的写得很完整，有的只有半页大纲。没个标准很难挑。

它怎么做

你给一个文件夹路径，它在这个文件夹里就地整理，只移动和改名，不改任何文件的内容。

清点与提取 —— zip / rar / 7z / PDF / docx / pptx，连没有扩展名的文本文件都能认出来
先分类型再打分 —— 不是 skill 的（作业、设计稿、别人的输出产物）单独放，不占编号也不参与排序
五维评分 —— 完整度、结构化、实用度、原创性、交付物，每条都给出具体依据而不是一句「质量不错」
去重仲裁 —— 只有同一 skill 的不同版本才算重复；不同作者的同主题 skill 一律保留，重复的移入归档而不删除
分类编号落盘 —— 执行前先给你看完整的移动计划，确认了才动手
出报告 + 留账本 —— 一份《Skill分析报告》，加一份账本文件，下次只处理新增的
第二次跑只看新增。 整理过一次后，你往文件夹里丢新东西、或者新建一个「待整理」子目录， 再让它整理一次，它只处理变动的部分，已有条目的编号一个都不会变。

能做什么，不能做什么

边界写在前面，省得装完发现不是你要的。

✓ 它负责
  • 批量解压与文本提取
  • 判断哪些是 skill、哪些只是资料
  • 打分、分类、编号、去重
  • 就地移动改名，出报告
  • 增量整理，不推倒重来
✗ 它不负责
  • 把 skill 安装到你的 AI 客户端
  • 修改任何 skill 的内容
  • 帮你写新的 skill
  • 扫描你指定目录以外的地方
  • 删除文件（重复的只归档）
电脑端：完整可用 能读写本地文件夹就能跑完整流程。装了 Python 会快很多，没装也能走，只是慢一些，会分批做并支持中断续跑。
手机端：只出分析报告 手机上的智能体通常动不了本地文件。这时它会主动降级，第一句就告诉你「只出报告、不动文件」，然后把该怎么整理列成一份清单给你。

怎么安装

先下载上面的 zip，然后把下面这段话整个复制给你的 AI。各家客户端放 skill 的位置不一样，让它自己判断就行。

我下载了一个叫 skill-library-curator 的 AI skill，压缩包在我的下载目录里。

请帮我：
1. 判断我现在用的这个 AI 客户端把 skill 放在哪个目录
2. 把压缩包解压过去，保持 skill-library-curator 这个文件夹名不变
3. 装好后告诉我怎么触发它

这个 skill 的作用：整理一个装满 skill 收藏的文件夹，自动解压、
评分、分类、去重、编号，生成一份《Skill分析报告》，
第二次运行只处理新增的条目。
装好之后怎么用： 跟你的 AI 说一句「帮我整理这个文件夹里的 skill」， 再把文件夹路径给它，或者直接把文件夹拖进对话框。 它会先告诉你有多少条目、大概要多久、会在哪两处停下来问你，然后才开始。

动手前它会自动备份。 备份是一份完整副本，放在你那个文件夹的旁边， 整理完会告诉你在哪，删不删由你决定。
这个 skill 是在一次真实整理中打磨出来的 —— 判据里的每一条反例，都是先踩过才写下的。
