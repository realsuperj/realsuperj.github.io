周期汇报助手

聊天记录、任务清单、会议纪要、表格片段散落各处。
这个 skill 按天归档、补齐日报，再按你的口令生成可直接复制的最终汇报稿和可追溯的事实底稿。

它解决什么

如果你也在写周报、月报或阶段汇报，这几件事应该很熟悉。

每次写汇报，都要从头翻材料聊天记录往上翻，表格里找数字，邮件里找结论，拼完才能开始写。
粘给 AI 能出一版，交出去还得自己改好不容易拼起来丢给 AI，出来的内容还要删路径、削过程、自己重写口径。
交上去才发现，数字对不上出处领导追问一句数字从哪来，又得回头翻聊天和表格，说不清有没有推断。
这份交上去了，下个周期还得整套再来周末、月末、年末，材料换了，找、拼、改还是同一套流程。

它怎么做

你把零散材料丢进来，它按天记下；到点由你说「生成周报」或「生成月报」，确认范围后才出稿。

先建汇报档案 —— 缺一项问一项，写下时区、业务、角色、汇报对象和一周起止
按天追加四类材料 —— 工作、反馈、学习、背景按发生日追加，同一天丢多次也不会覆盖
补齐有材料的日报 —— 有材料没日报的日子从旧到新补事实层；哪天没材料就不凭空写一天
生成前先对范围 —— 先列出周期、将读取的文件和缺口；你确认后才落盘，已有稿件会走重生成
先底稿再提炼终稿 —— 先写带出处的事实底稿，再提炼可直接复制到 PPT 的最终汇报稿
任意结论都能回读 —— 指向一句结论时，回读日报和原材料，说明依据，承认有没有推断
每天打开只补日报，更高周期等你开口。 周末说「生成周报」，月底说「生成月报」。缺结果、缺数字会先列缺口，不会编造。

能做什么，不能做什么

边界写在前面，省得装完发现不是你要的。

✓ 它负责
  • 按天归档工作、反馈、学习、背景四类材料
  • 补齐有材料的日报，空日不编造
  • 按口令生成周报、月报、季度、半年和年终汇报
  • 同时给出可复制的最终稿和可追溯的事实底稿
  • 把任意结论回读到日报和原材料
✗ 它不负责
  • 不接公司系统账号，也不自动拉数
  • 材料里没有的数字、收益和评价一律不写
  • 不会在周末或月末自动提醒你生成汇报
  • 学习没应用到工作或决策，不写进成果
  • 上游日报或报告待更新时，先拦住，不硬出正式稿
Cursor / Claude Code / Trae：完整可用安装 Skill 后，材料落在本地数据目录。每天丢新材料，到点由你说「生成周报」或「生成月报」。
豆包 / Kimi / ChatGPT：当场出一份可用通用提示词当场整理一份汇报。换对话不会记住每天记录，需要重新粘贴材料和提示词。

怎么安装

先下载上面的 zip，然后把下面这段话整个复制给你的 AI。各家客户端放 skill 的位置不一样，让它自己判断就行。

我下载了一个叫 periodic-report-assistant 的 AI skill，压缩包在我的下载目录里。

请帮我：
1. 判断我现在用的这个 AI 客户端把 skill 放在哪个目录
2. 把压缩包解压过去，保持 periodic-report-assistant 这个文件夹名不变
3. 装好后告诉我怎么触发它

这个 skill 的作用：把工作、反馈、学习、任务背景按天存档，
补齐日报，并按口令生成周报、月报、季度、半年和年终汇报。
只使用已有材料，不编造数字和结果。
装好之后怎么用： 跟 AI 说「记录今天」，把聊天摘录、任务、纪要或表格丢过去，说清是哪一天。同一天可以丢多次。

到点由你开口。 说「生成周报」或「生成月报」，先看它列出的日期和缺口，确认后再出正式稿。想核对一句结论，直接问「这句话依据是什么」。
这个 skill 是从真实的周报到月报流程里打磨出来的 —— 能交的终稿和能回读的底稿，必须拆开写。
