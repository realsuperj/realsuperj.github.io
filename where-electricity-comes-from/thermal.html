火从燃料到灯泡
一座火电厂怎么把燃料变成电

火电是一个「燃料家族」：煤、天然气、燃油、生物质都能烧出驱动热机的热量。先认清不同燃料的差别，再深入看燃煤电厂如何从燃烧走到并网。

SCROLL
00 · 燃料家族

火电不只烧煤

「火力」指的是燃烧放热驱动热机发电。燃料不同，前端装置与效率、排放、调峰能力差很多；后半程「热 → 机械 → 电」才更接近。四种常见燃料，各自的典型路线如下。

燃煤 · 朗肯循环汽轮机

示意：煤 → 磨细 → 锅炉产汽 → 汽轮机 → 发电机

典型路线

磨煤后喷入锅炉燃烧产汽，汽轮机带动发电机；凝汽冷却后水再回炉。

装置特征

标志是高大锅炉房、冷却塔与长烟囱；单机常 600–1000 MW。

应用场景

基荷与调峰主力；坑口电厂、港口煤运沿线常见。

效率 / 排放

效率约 38–45%；粉尘与硫氮需末端治理，碳排仍高。

天然气 · 燃机或联合循环

示意：天然气 → 燃气轮机发电 → 余热锅炉 → 汽轮机再发电

典型路线

燃机直接发电；大型项目常加余热锅炉与汽轮机，组成联合循环。

与煤电不同

没有磨煤大锅炉主流程；厂房更紧凑，启动更快。

应用场景

城市周边调峰、热电联产；对气源与气价更敏感。

效率 / 排放

联合循环可超 55%；几乎无粉尘，碳排约煤电一半量级。

燃油 · 锅炉或燃机，多作调峰备用

示意：储油 → 燃油锅炉产汽，或燃油燃机直接做功 → 发电

典型路线

可走燃油锅炉 + 汽轮机，也可走轻油/重油燃机，后半程仍是热机发电。

与煤电不同

燃料贵、罐区紧凑；少见超大型基荷煤电那种体量。

应用场景

岛屿、应急备用、部分老旧调峰机组；大陆大型电源占比很低。

效率 / 排放

通常不及先进煤电与气电联合循环；仍需硫氮治理。

生物质 · 小锅炉蒸汽路线

示意：生物质进料 → 锅炉产汽 → 汽轮机 → 发电机（主机布局接近煤电）

典型路线

秸秆、林木剩余物等进锅炉燃烧产汽，汽轮机发电，主机很像小型燃煤机组。

与煤电不同

热值低、收集半径有限；锅炉更防结渣腐蚀，单机容量更小。

应用场景

农林产区就近消纳、垃圾焚烧发电，常兼废弃物处理。

效率 / 排放

热效率一般低于大型煤电；可持续原料在政策上常按低碳核算。

后文构造、剖面与四步，以燃煤汽轮机组（朗肯循环）为例展开。天然气发电常常不是「把煤换成气的同一套锅炉」，而是燃气轮机，或「燃机 + 余热锅炉 + 汽轮机」的联合循环。

燃料家族简史

四种燃料不是同时登场的：煤最早撑起公用电力，油与气后来补上灵活与清洁，生物质则更偏废弃物与就近消纳。

世界

1880s–

燃煤：早期公用电厂以燃煤蒸汽机/汽轮机为主，煤成为工业化电力的默认燃料。

20 世纪中

燃油：部分地区用燃油锅炉或燃机补峰、应急；油价高企后大型燃油基荷逐渐退场。

战后–今

天然气：燃气轮机与联合循环普及，气电成为调峰与相对清洁的化石电力主力之一。

近几十年

生物质：秸秆、林木剩余物与垃圾发电兴起，常兼废弃物处理，单机规模通常小于煤电。

中国

长期

燃煤为主：煤多油少气相对不足，火电电量长期由煤电扛起工业化与保供。

局部

燃油很少作主力：大陆大型电源极少依赖燃油；多见于特殊场景或历史机组。

近年增多

天然气调峰：沿海与负荷中心建设燃机/联合循环，服务尖峰与热电联产。

同步推进

生物质与垃圾发电：农林产区与城市固废处理带动一批中小型生物质机组。

01 · 构造

先认识一座燃煤火电厂

一座 600 MW 级燃煤电厂占地可达数十公顷。下图按「煤进来 → 蒸汽做功 → 电送出 → 水散热 → 烟气净化」排布。点右侧名称或左侧图形，两边会一起高亮。

01

煤仓

储存并向下供给原煤。煤先在这里汇集，再送去磨成煤粉，是整条燃烧链的起点。

02

锅炉

煤粉在炉膛燃烧，把给水加热成高温高压蒸汽。600 MW 机组每小时约烧 200 吨煤，蒸汽约 540–600°C。

03

汽轮机

高压蒸汽推动多级叶片高速旋转，转速约 3000 转/分，把蒸汽的膨胀功变成机械能。

04

发电机

与汽轮机同轴。转子磁场切割定子线圈，感应出约 20 kV 交流电，再经主变升压送出。

05

凝汽器

汽轮机乏汽在这里被冷却成水，形成真空帮助继续做功；废热主要由循环冷却水带走。

06

冷却塔

把循环冷却水的热量排到大气。双曲线高塔是煤电厂最显眼的外形特征之一。

07

环保装置与烟囱

烟气先经除尘、脱硫、脱硝，再从厂区远端的高烟囱排出。图中上方是脱硫除尘设备，最右侧高塔才是烟囱，与发电机分开布置。

02 · 转换

化学能变成电能，一共四步

整个过程是一连串的能量"接力"：化学能 → 热能 → 蒸汽机械能 → 电能。核心工艺叫朗肯循环 —— 烧煤产汽、汽推轮机、轮带发电机、乏汽冷凝成水再泵回锅炉。先看一眼流程剖面，再逐步拆解。

主流程剖面 · 蒸汽与水循环（示意）

琥珀虚线 = 高温蒸汽 青色虚线 = 冷凝水 / 给水
01

煤燃烧 → 把水烧成高压高温蒸汽

磨煤机把煤磨成细粉，经燃烧器喷入炉膛与空气混合燃烧，火焰中心温度可达 1300°C 以上。热量通过水冷壁、过热器传递给管道中的水，最终产出过热蒸汽。亚临界机组蒸汽约 540°C / 17 MPa；超临界机组参数超过水的临界点（374°C / 22.1 MPa），效率更高；超超临界可达 600°C 级、效率约 45% 以上。

典型蒸汽参数 540–600°C ｜ 17–25 MPa ｜ 煤耗约 270–300 g/kWh
02

蒸汽推动汽轮机叶片旋转

高压蒸汽先进入高压缸做功，再经再热器加热后进入中压缸、低压缸逐级膨胀。每一级叶片把蒸汽的内能变成轴的旋转动能。600 MW 机组的汽轮机通常分 3 缸（高+中+低），整根轴长近 10 米，转速锁定 3000 转/分 —— 因为电网频率 50 Hz 要求同步转速。

转速 3000 转/分（50 Hz） ｜ 排汽真空约 −95 kPa
03

汽轮机轴带动发电机

汽轮机与发电机刚性联轴，同轴旋转。发电机转子上的励磁绕组通直流后变成电磁铁，旋转时磁场切割定子上的三相线圈，感应出与电网同步的 50 Hz 交流电 —— 原理与风机、水轮发电机完全相同，都是电磁感应。600 MW 机组发电机出口电压约 20 kV，电流可达近 2 万安培。

出口电压 约 18–22 kV ｜ 单机容量 600 / 1000 MW 级
04

凝汽回收 · 升压并网 · 烟气净化

做功后的"乏汽"进入凝汽器，被循环冷却水冷凝成水，由给水泵升压后送回锅炉 —— 完成闭环。同时，厂内主变压器把 20 kV 升至 220 kV 或 500 kV 并入电网。燃烧产生的烟气则经除尘（捕集 99%+ 飞灰）、脱硫（脱硫率 95%+）、脱硝后，才从烟囱排入大气。

厂内升压 20 kV → 220/500 kV ｜ 全厂效率 约 38–46%
图解 · 朗肯循环

为什么蒸汽做功后还要冷凝回来再烧？

闭环才能反复做功：如果蒸汽推完汽轮机就直接排入大气，每小时要消耗数千吨纯净水，任何河流都供不起。冷凝成水、泵回锅炉，水在系统里循环使用，只需偶尔补少量损耗。

真空 = 更大的推动力：凝汽器把排汽压强降到约 0.005 MPa（真空），相当于在叶片出口"抽"着蒸汽继续膨胀，汽轮机两端压差越大，同样多的蒸汽能多做功。

代价是大量废热：朗肯循环的"硬伤"在于，蒸汽在凝汽器里必须释放约 60% 的输入热量才能变回液态水 —— 这些热从冷却塔散入大气，是火电效率只有约 40% 的主因。提高蒸汽参数（超临界/超超临界）和再热，都是在尽量压缩这部分损失。

03 · 输送

发出的电，去了哪里

火电厂单机容量大 —— 一台 600 MW 机组满发时相当于 120 台 5 MW 风机同时转。厂内主变压器把 20 kV 升至 220 kV 或 500 kV，才能高效送入国家级输电网络。

变电站 / 变压器 输电铁塔 流动虚线 = 电流传输方向

简单说：发电机（≈20 kV）→ 厂内主变压器 → 升压站（220/500 kV）→ 高压线路远距离输送 → 区域变电站降压（10 kV）→ 配电网 → 工厂与居民用户。 火电厂通常建在煤炭运输便利或水源充足的地方，单机 600–1000 MW，是电网的"重型基荷电源" —— 电压一路升高再降低，原理与风电相同：高压低流，减少线路发热损耗。

04 · 快问快答

几个常见的好奇

看完全流程，你可能还有这些疑问。

火电只有煤吗？

不是。煤、天然气、燃油、生物质都属于火力发电「燃料家族」。中国电量里燃煤占比最高；天然气常走燃机或联合循环，效率与调峰特性都不同于磨煤锅炉。

煤电效率为什么只有约 40%？

卡诺定理告诉我们：即使完美热机，效率也受限于高温热源与低温冷源之间的温差。实际锅炉出口约 600°C，冷却塔出口约 30°C，理论上限大约 65% 左右。再加上排烟带走约 5–8% 热量、机械摩擦与辅机耗电，600 MW 级机组实际效率约 38–42%，超超临界可达 45% 以上 —— 剩下 55%+ 的能量变成了烟囱热损失和冷却塔散失的废热。

「清洁煤电」指的是什么？

专指燃煤机组的末端治理，不是零碳：电除尘捕集 99.9% 以上的飞灰，石灰石-石膏湿法脱硫脱除 95%+ 的 SO₂，SCR 脱硝把 NOₓ 降到 50 mg/m³ 以下。烟囱冒的"白烟"主要是水蒸气。但 CO₂ 仍随烟气排出 —— 深度减排要靠碳捕集或燃料替代。

为什么电网还需要火电？

风光出力随天气波动，需要能调节出力的电源"托底"。燃煤机组可深度调峰，气电启动更快，二者都承担灵活性角色。在储能大规模普及之前，火电仍是保障频率稳定与供电可靠的"压舱石"。

历史延伸

火电如何从街区电厂走到超超临界

从发明到落地，各摘几段关键节点。

世界

1882

Pearl Street：爱迪生在纽约建成早期商用燃煤电厂，电开始以公用事业方式售卖。

20 世纪

汽轮机取代往复蒸汽机：单机容量与蒸汽参数一路攀升，火电成为工业化国家的电力骨架。

战后–今

超临界与联合循环：煤电追求更高参数提效；气电则以燃机/联合循环提供灵活低碳化石电力。

中国

1882 前后

口岸早期电厂：上海等口岸出现中国最早的电灯与火电实践，电力随开埠城市进入日常生活。

1950s–80s

煤电托起工业化：在「煤多」禀赋下，火电装机与电网同步扩张，成为电量绝对主力。

近年

超超临界 + 灵活改造：新建煤电效率逼近上限，存量机组强化调峰，服务高比例风光电网。

SUMMARY

一句话说完全过程

以燃煤为例：煤在锅炉里燃烧，化学能变成高温蒸汽；蒸汽推动汽轮机，变成机械能；汽轮机带动发电机，变成电能；乏汽冷凝回炉，烟气净化后排出；电流经主变升压送上电网。气电等燃料换了前端热机，但「热 → 转轴 → 电」的终点相同。
